 
# ShopEase – E-Commerce Website

ShopEase is a responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for browsing products, searching items, and managing a shopping cart.

## 🚀 Features

- Responsive website design
- Navigation menu
- Hero section with promotional content
- Product categories
- Featured products with prices
- Product search functionality
- Add to Cart functionality
- Remove individual items from the cart
- Clear the entire shopping cart
- Automatic cart total calculation
- Cart item count
- Customer reviews section
- Promotional offer section
- Footer with useful information

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Search and shopping cart functionality

## ⚙️ How to Run the Project

1. Download or clone the project repository.
2. Open the `ShopEase` folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code to run the website locally.

## 🛒 How It Works

1. Open the website to view the homepage.
2. Browse products and categories.
3. Use the search box to find products.
4. Click **Add to Cart** to add a product to the shopping cart.
5. Open the cart to view selected products and the total price.
6. Remove individual products or clear the entire cart.

## ⚠️ Limitations

- This is a front-end project; it does not include a backend server.
- Product information is sample data.
- The shopping cart does not persist after a page refresh.
- User authentication and online payment are not implemented.
- Product images depend on the image URLs used in the HTML file.

## 🎯 Project Objective

The main objective of ShopEase is to demonstrate the development of a responsive e-commerce website using core web technologies. It helps demonstrate practical knowledge of HTML, CSS, JavaScript, DOM manipulation, search functionality, and basic shopping cart logic.
